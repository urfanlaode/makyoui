# MakyoUI

UI components with Typescript, TailwindCSS, and Storybook.


## Stack

- Vite - Build tool and server
- React - UI library
- React Router Dom - Routing
- TailwindCSS - Styling
- Class Variance Authority - Variant management
- React Feather - Icon library
- Storybook - Component documentation

## Installation

```
# Clone the repository
git clone https://github.com/urfanlaode/makyoui.git
cd makyoui

# Install dependencies
npm install

# Start development server
npm run dev

# Start Storybook
npm run storybook

# Build for production
npm run build

# Build Storybook
npm run build-storybook
```

```bash
npm install
```

## Usage
